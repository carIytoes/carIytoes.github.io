About

I'm an undergraduate electrical engineering student at the University of Houston, concentrating in Nanosystems. My interest sits on the process side of semiconductor manufacturing — the equipment, chemistry, and statistical methods that turn a wafer into working devices at scale.

RUN — UHNF·RIE
Summer research, 8 weeks
Plasma etch Bayesian opt. AFM

RIE Process Optimization of Silicon (SF₆/Ar)

Objective Optimize an SF₆/Ar reactive-ion etch recipe on an Oxford Instruments Plasmalab System 100 ICP at the UH Nanofabrication Facility.
Method Designed a physics-informed Bayesian optimization framework using a random-forest surrogate model and a Central Composite Design (CCD) to explore the process parameter space efficiently.
Result Direct experimental results (etch depth, AFM roughness) were inconclusive due to photolithography and surface-preparation challenges — so the framework itself, built to be robust to noisy experimental data, became the primary contribution.

RUN — SECOM·ML
Independent project
Python Random forest SMOTE

Wafer Failure Prediction on the SECOM Dataset

Objective Predict semiconductor wafer pass/fail outcomes from sensor data, built in preparation for a TSMC equipment engineer internship application.
Method Cleaned and modeled the SECOM manufacturing dataset in Python using scikit-learn, applying a Random Forest classifier and SMOTE to address severe class imbalance between pass and fail wafers.
Result A working classification pipeline connecting fab sensor data to actionable yield predictions — the kind of tool an equipment engineer would use to flag at-risk lots early.
